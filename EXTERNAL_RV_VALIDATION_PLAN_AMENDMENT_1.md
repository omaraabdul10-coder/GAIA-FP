# Amendment 1 to EXTERNAL_RV_VALIDATION_PLAN.md (9 Nov 2026, before any label or score was computed)

1. VizieR was unreachable, so SB9 was read from its own server (sb9.astro.ulb.ac.be, SB9public.tar.gz). Same catalogue.
2. SB9 gave 5 position matches; the NASA Exoplanet Archive gave 0 matches with non-sealed candidates. Only match counts
   were seen; no label, period comparison or score was computed.
3. Added source: **SBX** (Merle et al. 2026, MNRAS 547, the successor of SB9; https://astro.ulb.ac.be/sbx), read with the
   same cross-match and the same label rules. Where SB9 and SBX give the same system, the SBX orbit is used;
   where a system has several orbits, the most recent orbit with a period match is used.
4. Everything else in the plan is unchanged, including the ≥ 5 positives and ≥ 5 negatives condition for E1/E2.
