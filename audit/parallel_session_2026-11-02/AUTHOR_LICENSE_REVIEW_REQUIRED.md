# Owner review required before publication

- Add the confirmed creator(s), ORCID(s), affiliations and author order.
- Confirm the project owner has authority to license the code and derived files. The original project snapshot has no top-level LICENSE file; this draft intentionally does not invent a license.
- Check any third-party catalogue terms and required acknowledgements before redistribution. Gaia DR3 documentation states that Gaia data are free to use provided credit is given to ESA/Gaia/DPAC.
- Review the original public repository for personal/institutional information before linking it to a public deposit. This supplement's metadata template omits those details until the project owner confirms what should be public.
- The existing OSF DOI strings in the project README refer to preregistration records, not this new supplement. Verify those records before linking them.
- Do not use an abstract/title saying GAIA-FP is independently validated for compact companions or that Gaia DR4 results exist.
